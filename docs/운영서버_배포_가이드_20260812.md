## 0. 왜 PC와 서버가 다른가?

| 원인 | 증상 | 조치 |
|------|------|------|
| **WAR만 배포, DB 메뉴 SQL 미실행** | 심사조서 보고항목선택이 조서작성/보고항목서식 아래에 있음 | §2-③ 메뉴 패치 **필수** |
| **globals.properties AI 항목 누락·구버전** | AI 예산도우미 동작 불량·느림·빈 답변 | §2-④ AI 설정 병합 |
| **인덱스 미적용** | 내부자료검색 매우 느림 | §2-② 인덱스 |
| **브라우저·Tomcat 캐시** | 옛 JS 화면 (`aiChat.js?v=` 구버전) | Ctrl+F5, `work` 캐시 삭제 |

> **AI 예산도우미와 심사조서 개선은 같은 WAR 1개**입니다. 별도 프로젝트 배포가 아닙니다.

## 2. 적용 순서 (서버관리자 체크리스트)

```
□ ① 운영 DB 백업
□ ② 인덱스 적용 (check → apply)
□ ③ 메뉴 패치 (필수 — WAR만으로는 안 됨)
□ ④ globals.properties AI 설정 병합
□ ⑤ Tomcat 중지 → WAR 교체 → 기동
□ ⑥ Ctrl+F5 스모크 테스트 (§4)
```

### ① DB 백업

기관 표준 절차로 CUBRID 백업.

### ② 인덱스

```powershell
cd <배포패키지 또는 GitHub clone 루트>

.\scripts\check-ai-indexes.ps1 -DbPassword "운영DB비밀번호"
.\scripts\apply-indexes.ps1 -DbPassword "운영DB비밀번호"
```

`MISSING`이 남으면 내부자료검색이 PC 대비 매우 느립니다.

### ③ 메뉴 패치 (**필수**)

```powershell
.\scripts\apply-menu-budget-select.ps1 -DbPassword "운영DB비밀번호"
```

또는:

```powershell
.\deploy\deploy-db.ps1 -DbPassword "운영DB비밀번호" -RunMenuPatch
```

**기대 결과 (예산안관리 하위):**

| menu_cd | 메뉴명 | URL |
|---------|--------|-----|
| MUBG05000 | 조서·집계 항목선택 | `/budget/budgetSelectNew.do` |
| MUBG05100 | 심사조서 보고항목선택 | `/budget/budgetSelectAttr.do` |

점검:

```powershell
.\scripts\check-menu-budget-select.ps1 -DbPassword "운영DB비밀번호"
```

→ `OK: 메뉴 배치 정상` 이어야 합니다.

### ④ globals.properties

1. 운영 파일 백업: `globals.properties.bak.YYYYMMDD`
2. `deploy/globals.properties.ai-snippet.example` 내용을 **맨 아래**에 병합
3. **8/12 신규·갱신 키** (이미 있으면 값만 갱신):

```properties
# JSON보내기
Globals.AiInternalExportMaxRows = 8000
Globals.AiInternalExportMaxBiz = 2500

# 예산운용지침 (검색 품질·속도)
Globals.AiManualMaxPages = 3
Globals.AiManualExcerptChars = 2200
Globals.AiManualSummaryChars = 6500
Globals.AiManualPromptChars = 3600
Globals.AiManualMaxFiles = 4
Globals.AiManualLlmMaxFiles = 2
Globals.AiManualUseLlm = true

# 속도 (운영 권장)
Globals.AiReportDbOnly = true
Globals.AiEnableBroadSearch = false
Globals.AiQueryTimeoutSec = 45
Globals.ClovaStream = false
Globals.AiLawGoKrOc = (발급받은 OC)
Globals.AiManualStorePath = C:/bcjis/upload/ai-manual/
```

4. 매뉴얼 폴더 존재·쓰기 권한 확인
5. WAS → `99.1.82.207:8080`, `www.law.go.kr` 방화벽 확인

### ⑤ WAR 배포

```powershell
# 패키지 생성 (개발 PC)
.\scripts\package-deploy.ps1

# 서버 — 스크립트 사용 시
.\deploy\deploy-app.ps1 -TomcatHome "D:\was\apache-tomcat-9.0.89" -SkipBuild

# 또는 수동: Tomcat 중지 → webapps\bcjis-webapp 백업·삭제 → WAR 복사 → 기동
```

**주의:** 기동 후 `globals.properties`가 WAR 기본값으로 덮이지 않았는지 확인.

### ⑥ (선택) 사업설명서 테이블

사업설명서 매칭을 처음 쓰는 환경만:

```powershell
csql -u bcjisapp -p <비밀번호> bcjis -i scripts\create-tb-bizdesc.sql
```

## 5. 장애 시 빠른 대응

| 증상 | 조치 |
|------|------|
| 보고항목선택이 조서작성 아래 | `apply-menu-budget-select.ps1` 재실행 |
| AI 화면이 옛버전 | Ctrl+F5, Tomcat `work` 삭제, JS `?v=` 확인 |
| 내부검색 매우 느림 | `check-ai-indexes.ps1` → 인덱스 적용 |
| 법령 OC 키 없음 / 빈 요약 | `Globals.AiLawGoKrOc = nolbu0326` **필수**, law.go.kr 접근 |
| 보도자료 Connection reset | WAS→`www.busan.go.kr` 방화벽, 최신 WAR |
| 예산운용지침 단답·무관 내용 | globals `AiManual*` 키 갱신 후 재기동 |
| JSON보내기 실패 | 시작=종료 1년, `AiInternalExportMax*` 확인 |
| LLM 오류 | `ClovaEndpoint`, 방화벽 `99.1.82.207:8080` |
