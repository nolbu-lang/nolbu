## 왜 AI(법령·보도자료·운용지침)가 안 바뀌었나

| 증상 | 원인 | 이번 배포에서 해결 방법 |
|------|------|-------------------------|
| 법령조례 OC(`nolbu0326`) 미적용 | `globals.properties`에 `Globals.AiLawGoKrOc` 없음, 또는 **WAR 배포가 globals를 덮어씀** | **WAR 기동 후** `merge-globals-ai.ps1`로 강제 병합 |
| 보도자료/고시공고 `Connection reset` | ①구 WAR(시홈페이지 클라이언트 없음) ②**WAS→www.busan.go.kr:443 방화벽 차단** | 최신 WAR + 네트워크 점검 단계 + globals BaseUrl |
| 예산운용지침 답변 품질 미개선 | 구 WAR + `AiManual*` globals 미갱신 | 최신 WAR + `AiManualUseLlm/Excerpt/Prompt` 등 병합 |

메뉴 미반영과 동일하게, **WAR만 교체하면 AI 설정도 PC와 같아지지 않습니다.**

## 전달물

개발 PC:

```powershell
.\scripts\package-deploy.ps1
```

관리자에게 `bcjis-배포-YYYYMMDD.zip` 전체 전달.

필수 파일:

| 파일 | 역할 |
|------|------|
| `bcjis-webapp.war` | 앱 |
| `deploy/run-ops-deploy.ps1` | **일괄 실행 (이 파일만 실행하면 됨)** |
| `deploy/merge-globals-ai.ps1` | 법령OC·보도자료·운용지침 설정 병합 |
| `deploy/globals.properties.ai-snippet.example` | AI 설정 원본 |
| `scripts/apply-menu-budget-pc-parity.ps1` | 메뉴 동기화 |
| `scripts/sync-menu-budget-pc-parity.sql` | 메뉴 SQL |
| `scripts/apply-indexes.ps1` | 인덱스 |

**실행 금지:** `scripts/patch-menu-budget-copy.sql` (전년도[신규]를 숨김)

## 관리자 실행 방법 (한 번에)

서버에서 ZIP 압축 해제 후:

```powershell
cd <압축해제한 bcjis-배포-YYYYMMDD 폴더>

# URL이 http://99.1.1.39:8080/main/... 이면 ContextName=ROOT
.\deploy\run-ops-deploy.ps1 `
  -TomcatHome "D:\was\apache-tomcat-9.0.89" `
  -DbPassword "운영DB비밀번호" `
  -ContextName "ROOT"
```

`/bcjis-webapp/` 로 서비스 중이면:

```powershell
.\deploy\run-ops-deploy.ps1 `
  -TomcatHome "D:\was\apache-tomcat-9.0.89" `
  -DbPassword "운영DB비밀번호" `
  -ContextName "bcjis-webapp"
```

globals 경로가 다르면:

```powershell
.\deploy\run-ops-deploy.ps1 `
  -TomcatHome "..." `
  -DbPassword "..." `
  -ContextName "ROOT" `
  -GlobalsPath "D:\was\...\WEB-INF\classes\csframework\bcjisProps\globals.properties"
```

## 스크립트가 자동 수행하는 순서

| 순서 | 작업 | 자동 |
|------|------|------|
| 0 | `www.law.go.kr` / `www.busan.go.kr` 443 점검 | ○ (FAIL 시 화면 출력) |
| 1 | DB 인덱스 | ○ |
| 2 | 메뉴 PC 동기화 | ○ |
| 3 | Tomcat 중지 | ○ |
| 4 | WAR 교체 + work 캐시 삭제 | ○ |
| 5 | Tomcat 기동·explode 대기 | ○ |
| 6 | **globals AI 병합 (OC=nolbu0326 포함)** | ○ ← WAR **이후** |
| 7 | globals 반영 재기동 | ○ |

방화벽 FAIL이 나오면, 인프라에서 **WAS → www.busan.go.kr:443 (및 law.go.kr:443)** 허용 후  
같은 명령으로 **재실행**하면 됩니다. (개발자 피드백 불필요)

## 적용 후 화면 확인 (관리자 자체 확인용)

재로그인 + Ctrl+F5

1. **메뉴:** 조서·집계 → 전년도예산조서적용[신규] → 심사조서 보고항목선택 (`[삭제예정]`/`[매핑일괄테스트]` 없음)
2. **AI 법령조례:** OC 키 오류 없이 검색
3. **AI 보도자료/고시공고:** Connection reset 없이 목록
4. **AI 예산운용지침:** 금액·기준 포함 요약

```
  빠졌거나, WAR가 globals를 덮어 OC키가 사라진 경우입니다.
※ 이번 스크립트는 WAR 배포 후 globals를 다시 병합합니다.

※ 보도자료 Connection reset이 남으면 WAS→www.busan.go.kr:443 방화벽 허용이 필요합니다.
```
