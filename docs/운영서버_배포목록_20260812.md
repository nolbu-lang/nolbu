## C. globals.properties 필수 항목 (운영 서버)

기존 DB URL·계정은 **변경하지 않음**. 파일 맨 아래에 추가·갱신.

```properties
# ===== AI 예산도우미 (필수) =====
Globals.AiProvider = hyperclova
Globals.ClovaEndpoint = http://99.1.82.207:8080/llm-studio/v1/api/task/generate/syncapi/busan_ai_llm/budget_search
Globals.ClovaTimeoutMs = 120000
Globals.ClovaStream = false

# 내부자료검색 속도
Globals.AiReportDbOnly = true
Globals.AiEnableBroadSearch = false
Globals.AiNearbyYearCount = 0
Globals.AiQueryTimeoutSec = 45

# [필수] 법령·조례 — 미설정 시 "Globals.AiLawGoKrOc" 오류
Globals.AiLawGoKrOc = nolbu0326
Globals.AiLawOrdinOrgCd = 6260000

# [필수] 시홈페이지 보도자료·고시공고 — WAS→www.busan.go.kr 방화벽
Globals.AiBusanHomepageBaseUrl = https://www.busan.go.kr
Globals.AiBusanHomepageTimeoutMs = 20000

# 예산운용지침 PDF
Globals.AiManualStorePath = C:/bcjis/upload/ai-manual/
Globals.AiManualUploadAdminOnly = true
Globals.AiManualUseLlm = true
Globals.AiManualMaxPages = 3
Globals.AiManualExcerptChars = 2200
Globals.AiManualPromptChars = 3600
Globals.AiManualLlmMaxFiles = 2

# JSON보내기
Globals.AiInternalExportMaxRows = 8000
Globals.AiInternalExportMaxBiz = 2500
```

**방화벽 (WAS 서버 → 외부):**

| 대상 | 용도 |
|------|------|
| `99.1.82.207:8080` | 내부 LLM |
| `www.law.go.kr` | 법령·조례 |
| `www.busan.go.kr` | 보도자료·고시공고 |

- `MUBG05000` 조서·집계 항목선택 — 대/중/소·국고보조·금액
