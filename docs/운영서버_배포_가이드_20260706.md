## 2. 적용 방법 (관리자 — 두 가지 중 택 1)

### 방법 A — WAR 일괄 배포 (권장)

개발 PC 또는 CI에서 빌드된 **`bcjis-webapp.war`** 를 Tomcat에 교체합니다.

**전달받을 폴더:** `bcjis-배포-20260706` (또는 ZIP)

```
bcjis-배포-20260706/
├── bcjis-webapp.war          ← 필수
├── deploy/                   ← deploy-all.ps1, README
├── scripts/                  ← apply-indexes.ps1, create-indexes.sql
├── docs/                     ← 본 가이드 등
└── README-DEPLOY.txt
```

**적용 순서:**

```
1. 운영 DB 백업
2. (최초 1회 또는 loaddb 후) scripts\apply-indexes.ps1 -DbPassword "비밀번호"
3. globals.properties 에 AI·속도 설정 추가 (§4 참고) → Tomcat 재기동
4. Tomcat 중지
5. webapps\bcjis-webapp 폴더 삭제 (있으면)
6. bcjis-webapp.war → webapps\ 복사
7. Tomcat 기동
8. §5 시험 항목 확인
```

자동화:

```powershell
.\deploy\deploy-all.ps1 -TomcatHome "Tomcat설치경로" -DbPassword "DB비밀번호"
```

### 방법 B — GitHub 소스 변경분 덮어쓰기 후 빌드

소스를 직접 관리하는 서버에서 **동일 경로로 파일 복사** 후 Maven 빌드합니다.

**전달받을 폴더:** `bcjis-소스변경분-20260706` (또는 ZIP)

```
bcjis-소스변경분-20260706/
├── README-APPLY.txt          ← 적용 요약
├── MANIFEST.txt              ← 포함 파일 전체 목록
├── src/...                   ← 변경된 소스만 (동일 경로)
├── deploy/...
├── scripts/...
└── docs/...
```

**적용 순서:**

```
1. 기존 bcjis 프로젝트 전체 백업
2. bcjis-소스변경분-20260706 압축 해제
3. MANIFEST.txt 목록 파일을 프로젝트 루트 기준 동일 경로에 복사(덮어쓰기)
4. Maven 빌드: scripts\build.ps1  또는  mvn clean package -DskipTests
5. target\bcjis-webapp.war 생성 확인
```

**Git clone으로 받는 경우:**

## 4. globals.properties 추가·확인 (필수)

기존 `globals.properties` **DB 접속 정보는 변경하지 않습니다.**  
아래만 **추가 또는 수정** (`deploy/globals.properties.ai-snippet.example` 참고):

```properties
Globals.AiReportDbOnly = true
Globals.AiMaxReportBlocks = 50

# 운영 검색 속도 (이번 배포 추가)
Globals.AiNearbyYearCount = 1
Globals.AiSearchAllYearsFallback = false
Globals.AiPerfLog = true
```

수정 후 **Tomcat 재기동** 필수.
