# 운영 서버 배포 미반영 — 원인분석 (2026-08-16)

> **대상:** 개발자·서버관리자  
> **증상:** `http://99.1.1.39:8080/main/main.do` 좌측 메뉴가 PC(`localhost:8080/bcjis-webapp`)와 다름  
> **증거:** 서버에 `[삭제예정]`, `전년도예산/조서 적용[매핑일괄테스트]` 등이 남아 있고,  
> `조서·집계 항목선택` / `전년도예산조서적용[신규]` / `심사조서 보고항목선택` 이 없음

---

## 1. 결론 (한 줄)

**애플리케이션 WAR 교체만으로는 메뉴가 바뀌지 않습니다.**  
메뉴는 **운영 CUBRID `TB_MENU`** 에 저장되며, **DB 메뉴 SQL을 실행하지 않았거나 검증하지 않은 것**이 1차 원인입니다.  
추가로, 기존 배포 패키지의 메뉴 패치는 **PC 현재 구성과 불완전 일치**했고, **오늘까지의 최신 기능은 아직 서버 패키지에 포함되지 않았습니다.**

---

## 2. 원인 상세

### 원인 A — 메뉴는 DB, WAR가 아님 (가장 중요)

| 구분 | PC (정상) | 서버 (현재 화면) |
|------|-----------|------------------|
| 메뉴 저장 위치 | `TB_MENU` | `TB_MENU` (별도 DB) |
| 기대 메뉴 | 조서·집계 / 전년도[신규] / 보고항목선택 | 없음 |
| 실제 메뉴 | (로컬 DB에 반영됨) | `[삭제예정]`, `[매핑일괄테스트]` 등 구 구성 |

8/7·8/12 가이드에도 **「메뉴 SQL 필수 / WAR만으로는 안 됨」** 이 명시되어 있습니다.  
서버 화면이 구 메뉴라면, 아래 중 하나입니다.

1. `apply-menu-budget-select.ps1` (**메뉴 패치**) 미실행  
2. 실행했으나 **다른 DB·계정**에 적용  
3. 실행 후 **`check-menu-budget-select.ps1` / 스모크 테스트 미확인**  
4. PDF 가이드만 전달되고 **WAR·scripts ZIP이 함께 적용되지 않음**

→ **붙임 이미지의 메뉴는 DB가 갱신되지 않았다는 직접 증거**입니다.

### 원인 B — 기존 메뉴 패치 범위가 PC와 다름

| 항목 | 8/12 `patch-menu-budget-select-all.sql` | PC 현재 |
|------|------------------------------------------|---------|
| 조서·집계 / 보고항목선택 추가 | ○ | ○ |
| `[삭제예정]` 일괄 숨김 | △ (일부만) | ○ (정리됨) |
| `전년도예산조서적용[신규]` + `budgetCopyNew.do` | ✕ | ○ |
| `patch-menu-budget-copy.sql` | **New URL을 숨기고 `budgetCopy.do`로 통일** | PC는 **New를 사용** |

즉, 8/12 패치를 **완벽하게 실행해도**  
서버에는 여전히 `[삭제예정]`·`[매핑일괄테스트]`가 남을 수 있고,  
`전년도예산조서적용[신규]`(개선 화면)는 **의도적으로 빠지거나 오히려 숨겨질 수** 있습니다.

### 원인 C — 컨텍스트·배포 경로 혼동 가능

| 환경 | URL |
|------|-----|
| PC | `http://localhost:8080/bcjis-webapp/main/main.do` |
| 서버 | `http://99.1.1.39:8080/main/main.do` (ROOT 가능성) |

WAR를 `bcjis-webapp`에만 올리고 실제 서비스는 **ROOT** 이거나,  
그 반대인 경우 **옛 앱이 계속 서비스**될 수 있습니다.  
메뉴 문제는 주로 DB이지만, **기능/JS 미반영** 시 경로 확인이 필요합니다.

### 원인 D — 오늘까지의 최신 작업은 아직 미패키징

아래는 8/12 배포 이후·당일 PC 작업으로, **서버에 아직 공식 배포되지 않은 상태**입니다.

- 전년도예산조서적용[신규] 적용표시 유지·자동매핑 속도·**동시적용 대기열**
- 메뉴 순서: 조서·집계 → 전년도[신규] → 보고항목선택  
- (누적) AI 예산도우미 개선분 — globals·인덱스와 함께 재확인 필요

### 원인 E — “가이드 PDF 배포” ≠ “시스템 적용 완료”

가이드 문서(8/7, 8/12 PDF)는 **절차서**입니다.  
실제 적용은 **WAR + DB SQL + globals** 가 서버에서 실행되고,  
**체크리스트·스모크 테스트에 체크**되어야 완료입니다.

## 3. 서버에서 바로 확인하는 방법 (관리자)

```sql
-- 예산안관리 하위 활성 메뉴
SELECT menu_cd, menu_nm, url, line_up_no, use_yn
  FROM tb_menu
 WHERE up_menu_cd = 'MUBG00000'
   AND use_yn = 'Y'
 ORDER BY line_up_no;
```

| 결과 | 판정 |
|------|------|
| `MUBG05000` / `MUBG10000` / `MUBG05100` 없음 | **메뉴 SQL 미적용** |

| 위 3개만(또는 +예산안생성 등 정상 메뉴) | 메뉴 OK → WAR/캐시/경로 확인 |

## 4. AI 예산도우미(8/7 이후) 미반영 — 추가 원인

증상: 법령조례 OC(`nolbu0326`) 미적용, 보도자료/고시공고 `Connection reset`, 예산운용지침 답변 품질 미개선.

| 증상 | 원인 | 비고 |
|------|------|------|
| OC 키 미적용 | 운영 `globals.properties`에 `Globals.AiLawGoKrOc=nolbu0326` 없음 | 코드는 globals에서 읽음 (`AiLawGoKrClient`) |
| OC가 다시 사라짐 | **WAR 배포 시** `WEB-INF/classes/.../globals.properties`가 WAR 기본값으로 **덮임** | 병합을 WAR **이전**에만 하면 실패 |
| Connection reset | WAS→`www.busan.go.kr:443` 차단, 또는 구 WAR에 시홈페이지 클라이언트 없음 | 방화벽+최신 WAR 둘 다 필요 |
| 운용지침 품질 | 구 WAR + `AiManual*` globals(Excerpt/Prompt/UseLlm 등) 미갱신 | globals+최신 WAR |

**조치:** `deploy/run-ops-deploy.ps1` 이 **WAR 기동 후** `merge-globals-ai.ps1`로 OC·보도자료·운용지침 키를 강제 병합합니다.  
회신 절차 없이 관리자가 스크립트만 순서대로 실행하면 됩니다.
