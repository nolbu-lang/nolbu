## 2. 적용 순서 (권장 — 이 순서대로)

```
① 운영 DB 백업
② (최초/누락 시) AI·조회용 인덱스 적용
③ (해당 시) 메뉴·사업설명서 SQL
④ globals.properties 에 AI 설정 블록 추가/갱신
⑤ Tomcat 중지 → WAR(또는 exploded) 교체 → 기동
⑥ 브라우저 Ctrl+F5 후 스모크 테스트
```

### ① DB 백업

기관 표준 절차로 CUBRID 백업.

### ② 인덱스 (검색 속도 — 필수에 가깝음)

```powershell
cd <배포패키지 또는 소스루트>

# 누락 확인
.\scripts\check-ai-indexes.ps1 -DbPassword "운영DB비밀번호"

# MISSING 이 있거나 최초 1회
.\scripts\apply-indexes.ps1 -DbPassword "운영DB비밀번호"
```

`MISSING`이 남아 있으면 AI 내부검색이 PC 대비 매우 느립니다.

### ③ 선택 SQL (기능 사용 시에만)

| 스크립트 | 언제 |
|----------|------|
| `scripts/patch-menu-budget-copy.sql` | 전년도예산/조서 적용 메뉴 URL 통합 (미적용 시 1회) |
| `scripts/add-menu-budget-select-split.sql` | 예산조회 메뉴 분리 반영 시 |
| `scripts/rename-menu-attr-*.sql` | 속성/분류 메뉴명 변경 시 |
| `scripts/create-tb-bizdesc.sql` 및 `alter-tb-bizdesc-*.sql` | **사업설명서 매칭** 기능 사용 시 |
| `scripts/seed-comm-seq.sql` | loaddb·DB 재구축 직후만 — **운영 중이면 DBA 협의** |

### ④ globals.properties (DB 접속은 유지)

1. 운영 파일 백업: `globals.properties.bak.YYYYMMDD`
2. `deploy/globals.properties.ai-snippet.example` 내용을 **파일 맨 아래**에 병합
3. 이미 AI 블록이 있으면 **신규 키만** 추가·갱신:

```properties
# 속도
Globals.AiReportDbOnly = true
Globals.AiEnableBroadSearch = false
Globals.AiNearbyYearCount = 0
Globals.AiSearchAllYearsFallback = false
Globals.AiQueryTimeoutSec = 45
Globals.ClovaStream = false

# 법령
Globals.AiLawGoKrOc = (발급받은 OC)

# 매뉴얼
Globals.AiManualStorePath = C:/bcjis/upload/ai-manual/
Globals.AiManualUploadAdminOnly = true
Globals.AiManualUseLlm = true

# JSON 내보내기 상한
Globals.AiInternalExportMaxRows = 8000
Globals.AiInternalExportMaxBiz = 2500
```

전문은 `deploy/globals.properties.ai-snippet.example` 참고.

### ⑤ WAR 배포

**방법 A — 스크립트 (Windows WAS)**

```powershell
.\deploy\deploy-app.ps1 -TomcatHome "D:\was\apache-tomcat-9.0.89" -SkipBuild
# SkipBuild 없이 쓰려면 소스에서 빌드 가능한 PC에서 실행
```

**방법 B — 수동**

1. Tomcat **중지**
2. 기존 `webapps\bcjis-webapp.war` 및 풀린 `webapps\bcjis-webapp\` **백업 후 삭제**
3. 새 `bcjis-webapp.war` 복사
4. (exploded 배포 중이면) WAR 대신 클래스·JSP·JS 동기화 후 `work\Catalina` 캐시 삭제 권장
5. Tomcat **기동**
6. 기동 후 `globals.properties`가 WAR 기본값으로 덮이지 않았는지 확인  
   - 외부 config / 기존 파일 유지 정책이면 ④에서 수정한 파일을 다시 확인

**방법 C — DB+앱 일괄**

```powershell
.\deploy\deploy-all.ps1 -TomcatHome "Tomcat경로" -DbPassword "DB비밀번호"
# 이후 globals AI 항목은 반드시 수동 확인
```

## 4. 장애 시 빠른 대응

| 증상 | 조치 |
|------|------|
| 내부검색 매우 느림 | `check-ai-indexes.ps1` → 누락 인덱스 적용, `AiEnableBroadSearch=false` |
| AI 답변 없음 / LLM 오류 | `ClovaEndpoint`·방화벽, `ClovaStream=false` |
| 법령 0건·빈 요약 | `AiLawGoKrOc`, WAS→law.go.kr, 검색어 `법률명 제N조` |
| 매뉴얼 검색 안 됨 | `AiManualStorePath` 존재·권한, PDF 업로드 |
| JSON내보내기 실패 | 회계년도 시작=종료, 타임아웃·상한 설정 |
| 화면이 옛버전 | Ctrl+F5, `work` 캐시 삭제, JS `?v=` 확인 |
