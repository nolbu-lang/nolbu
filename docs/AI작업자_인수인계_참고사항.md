## 1. 이번 개선에 포함된 작업 범위

서버관리자에게 “무엇을 배포하는지”만 전달할 때 아래 두 축으로 설명하면 됩니다.

| # | 작업명 | 사용자 체감 |
|---|--------|-------------|
| **A** | **AI 예산편성 도우미** | 상단 「AI 예산도우미」 팝업 — 내부자료검색·일반자료검색·매뉴얼·법령·JSON내보내기 |
| **B** | **심사정보·예산편성 화면 개선** | 예산조회/복사, 조서작성, 사업설명서 매칭, 메뉴·성능 관련 |

※ 개발 대화명에 “AI budget assistant chatbot”이 반복되어도, **배포 단위는 위 A+B가 한 WAR**입니다.

## 3. 서버관리자에게 넘길 때 체크리스트

1. [ ] `docs/운영서버_배포_가이드_20260807.md` 전달 (또는 GitHub `main` 안내)
2. [ ] WAR 빌드본 또는 `.\scripts\package-deploy.ps1` 패키지 전달
3. [ ] `deploy/globals.properties.ai-snippet.example` — **기존 DB URL은 건드리지 말고 AI 항목만 추가**
4. [ ] DB: `scripts/apply-indexes.ps1` (누락 시 `check-ai-indexes.ps1`로 확인)
5. [ ] DB: **`scripts/apply-menu-budget-select.ps1`** — 조서·집계 / 심사조서 보고항목선택 메뉴 (**WAR만으로는 반영 안 됨**)
6. [ ] (해당 시) 사업설명서 매칭 테이블 SQL
7. [ ] WAS → LLM(`99.1.82.207:8080`), law.go.kr, 매뉴얼 폴더 경로 확인
7. [ ] 배포 후 Ctrl+F5, AI 팝업·내부검색·법령·내보내기 스모크 테스트

---

## 4. 건드리면 안 되는 것

| 항목 | 이유 |
|------|------|
| 운영 `globals.properties`의 DB URL·계정 | 서버별 비밀, Git 미포함 |
| 기존 업무 메뉴 URL을 임의 변경 | 메뉴 패치 SQL만 사용 |
| `AiEnableBroadSearch=true` 상시 ON | 운영 속도 급락 |
